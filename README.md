# Sreyneath Rom - Personal Portfolio Website

A modern, high-performance personal portfolio web application built with **React 18 / React 19**, **TypeScript**, **Tailwind CSS**, and **Motion (Framer Motion)**. Designed with a sleek glassmorphism aesthetic, dynamic multi-theme switcher, fluid micro-interactions, responsive navigation, and project modal showcases.

---
## 🛠️ Tech Stack

- **Core**: React 18+, TypeScript, Vite
- **Styling**: Tailwind CSS, CSS variables with dynamic theme attributes
- **Animation**: Motion (`motion/react`), `typed.js`
- **Icons**: Lucide React (`lucide-react`)
- **Responsive Architecture**: Mobile-first fluid layout with custom glassmorphism utilities

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Development
```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production
npm run build
```
